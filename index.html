Naruto Uzumaki Bot Privacy Policy

Effective date: October 16, 2026

This notice describes how the Naruto Uzumaki bot (the “Bot”) handles information when it runs in a Root community. The Bot is a fan-made community bot and is not affiliated with the Naruto rights holders.

Information the Bot processes

The Bot receives Root message events so it can recognize commands such as /help, /rank, and /clip, award experience points (XP), and respond to a small set of chat keywords. To award XP and show a member’s rank, it uses the member’s Root user ID and stores that member’s XP total in the Bot’s Root app data.

The current version does not save complete message text as a profile or message history. It processes message text while deciding whether to respond. A short XP cooldown is kept in memory while the Bot runs.

How information is used

Message events are used to provide the Bot’s commands, XP and level tracking, level-up notices, and occasional original themed replies. XP totals are used only for the Bot’s rank and leveling features.

Storage and retention

XP totals are stored in Root’s app data for the Bot and do not have an automatic expiration in the current version. The Bot has no self-service command to erase an XP record. Root operates the platform and its storage; see Root’s Privacy Policy for information about Root’s own handling of platform data.

Sharing and external links

The Bot posts its replies and XP notices in the Root channel where it was used. Its clip commands post links to promotional videos on YouTube; the Bot does not download or re-host those videos. If you open a YouTube link, YouTube may process information under its own privacy terms. The current Bot code does not send XP records to analytics or advertising services.

Your choices and privacy requests

You can choose not to interact with the Bot. For questions or privacy requests, contact the Bot operator through the repository issue page. Do not include your Root user ID or other sensitive information in a public issue. If an ID is needed to locate a record, ask for a private contact route first.

Changes to this notice

This notice may be updated if the Bot’s behavior or data handling changes. The effective date above will be updated when a new version is published.

Contact: GitHub Issues for this policy site. Please do not post sensitive information in a public issue.
